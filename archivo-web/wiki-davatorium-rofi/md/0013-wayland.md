# rofi >= 2.x.y supports Wayland

“Wayland support” has been merged into mainline in 2025 and has first been released with rofi 2.0.0

## Update, July 2020

A [pull request](https://github.com/davatorium/rofi/pull/1139) was opened to allow rofi to work under Wayland with Sway and some other window managers, but this PR was closed and spun off into a separate Wayland-compatible fork of rofi. If you are are interested, check out the [fork](https://github.com/lbonn/rofi) and send feedback there. The fork has meanwhile been merged
