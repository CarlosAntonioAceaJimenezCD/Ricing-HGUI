1. Open `~/.config/oomox/colors` on your computer and pick the theme which you are going to upload.

2. Open colors directory on Themix GitHub: https://github.com/themix-project/oomox/tree/master/colors

   Choose appropriate subdirectory for your theme. If you're not sure use `Contributed` one.

3. Create new file:

![](https://raw.githubusercontent.com/wiki/themix-project/oomox/images/examples/contribute_1.png)

4. Enter your theme name:

![](https://raw.githubusercontent.com/wiki/themix-project/oomox/images/examples/contribute_2.png)

5. Paste the theme contents from the file in `~/.config/oomox/colors/`:

![](https://raw.githubusercontent.com/wiki/themix-project/oomox/images/examples/contribute_3.png)

6. Propose new file (that will create a pull request):

![](https://raw.githubusercontent.com/wiki/themix-project/oomox/images/examples/contribute_4.png)

7. :fireworks:
