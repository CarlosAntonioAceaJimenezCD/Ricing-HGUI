1. Abre o directório `~/.config/oomox/colors` no teu computador e escolhe o tema que tu enviarás.

2. Abre o diretcório de cores no Themix GitHub: https://github.com/themix-project/oomox/tree/master/colors

   Escolhe o subdirectório apropriado para o teu tema. Se não tens certeza, utiliza `Contributed`.

3. Cria um novo ficheiro:

![](https://raw.githubusercontent.com/wiki/themix-project/oomox/images/examples/contribute_1.png)

4. Introduz o nome do teu tema:

![](https://raw.githubusercontent.com/wiki/themix-project/oomox/images/examples/contribute_2.png)

1. Cola o conteúdo do tema do ficheiro no directório `~/.config/oomox/colors/`:

![](https://raw.githubusercontent.com/wiki/themix-project/oomox/images/examples/contribute_3.png)

1. Propõe um novo ficheiro (que criará uma *pull request*):

![](https://raw.githubusercontent.com/wiki/themix-project/oomox/images/examples/contribute_4.png)
