1. Apri la cartella `~/.config/oomox/colors` sul tuo computer e scegli il tema che vai caricare.

2. Apri la cartella di colori sul Themix GitHub: https://github.com/themix-project/oomox/tree/master/colors

      Scegli la sottocartella appropriata per il tuo tema. Se non sei sicuro, usa quello «Contributed».

3. Crea un nuovo file:

![](https://raw.githubusercontent.com/wiki/themix-project/oomox/images/examples/contribute_1.png)

4. Inserisci il nome del tuo tema:

![](https://raw.githubusercontent.com/wiki/themix-project/oomox/images/examples/contribute_2.png)

5. Incolla i contenuti del tema dal file nella cartella `~/.config/oomox/colors/`:

![](https://raw.githubusercontent.com/wiki/themix-project/oomox/images/examples/contribute_3.png)

1. Proponi nuovo file (che creerà un *pull request*):

![](https://raw.githubusercontent.com/wiki/themix-project/oomox/images/examples/contribute_4.png)

7. :fireworks:
