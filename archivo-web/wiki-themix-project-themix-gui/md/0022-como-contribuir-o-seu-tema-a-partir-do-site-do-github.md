1. Abra a pasta `~/.config/oomox/colors` no seu computador e escolha o tema que você vai carregar.

2. Abra o diretório de cores no Themix GitHub: https://github.com/themix-project/oomox/tree/master/colors

   Escolha o subdiretório apropriado para o seu tema. Se você não tem certeza, use `Contributed`.

3. Crie um novo arquivo:

![](https://raw.githubusercontent.com/wiki/themix-project/oomox/images/examples/contribute_1.png)

4. Digite o nome do seu tema:

![](https://raw.githubusercontent.com/wiki/themix-project/oomox/images/examples/contribute_2.png)

5. Cole o conteúdo do tema do arquivo na pasta `~/.config/oomox/colors/`:

![](https://raw.githubusercontent.com/wiki/themix-project/oomox/images/examples/contribute_3.png)

1. Proponha novo arquivo (que criará uma *pull request*):

![](https://raw.githubusercontent.com/wiki/themix-project/oomox/images/examples/contribute_4.png)

7. :fireworks:
