1. Ouvrez le dossier `~/.config/oomox/colors` sur votre ordinateur et choissisez le thème lequel vous allez envoyer.

2. Ouvrez le répertoire de couleurs sur le Themix GitHub : https://github.com/themix-project/oomox/tree/master/colors
   Choissisez le sous-répertoire pour votre thème. Si vous n'êtes pas sûr, utilisez `Contributed`. 

3. Créez un nouveau fichier :

![](https://raw.githubusercontent.com/wiki/themix-project/oomox/images/examples/contribute_1.png)

1. Écrivez ton nom du thème :

![](https://raw.githubusercontent.com/wiki/themix-project/oomox/images/examples/contribute_2.png)

1. Collez les contenus du thème du fichier dans `~/.config/oomox/colors/` :

![](https://raw.githubusercontent.com/wiki/themix-project/oomox/images/examples/contribute_3.png)

1. Proposez un nouveau fichier que créra un *pull request* :

![](https://raw.githubusercontent.com/wiki/themix-project/oomox/images/examples/contribute_4.png)

7. :fireworks:
