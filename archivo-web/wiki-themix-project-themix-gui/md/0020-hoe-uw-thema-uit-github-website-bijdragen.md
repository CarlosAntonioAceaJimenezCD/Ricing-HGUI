1. Open `~/.config/oomox/colors` op uw computer en kies het thema dat u gaat uploaden.

2. Open de kleurenmap op Themix GitHub: https://github.com/themix-project/oomox/tree/master/colors

   Kies de juiste submap voor uw thema. Als u het niet zeker weet, gebruik dan een `Contributed`.

3. Maak een nieuw bestand:

![](https://raw.githubusercontent.com/wiki/themix-project/oomox/images/examples/contribute_1.png)

1. Schrijf uw themanaam:

![](https://raw.githubusercontent.com/wiki/themix-project/oomox/images/examples/contribute_2.png)

5. Plak de thema-inhoud uit het bestand naar `~/.config/oomox/colors/`:

![](https://raw.githubusercontent.com/wiki/themix-project/oomox/images/examples/contribute_3.png)

1. Stel een nieuw bestand voor (waarmee een pull request zal maken):

![](https://raw.githubusercontent.com/wiki/themix-project/oomox/images/examples/contribute_4.png)

7. :fireworks:
