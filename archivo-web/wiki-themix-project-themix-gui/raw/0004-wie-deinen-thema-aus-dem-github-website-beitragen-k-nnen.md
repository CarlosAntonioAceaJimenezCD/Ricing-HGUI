1. Öffne `~/.config/oomox/colors` bei deinem Computer und wähle das Theme aus, das du laden wirst.

2. Öffne das Farben-Verzeichnis beim Themix GitHub https://github.com/themix-project/oomox/tree/master/colors
   Wähle angemessenes Unterverzeichnis für dein Thema. Wenn du es nicht weißt, benütze einen `Contributed`. 

3. Erstelle eine neue Datei:

![](https://raw.githubusercontent.com/wiki/themix-project/oomox/images/examples/contribute_1.png)

4. Schreibe deinen Namen für das Thema:

![](https://raw.githubusercontent.com/wiki/themix-project/oomox/images/examples/contribute_2.png)

5. Füge die Thema-Inhalten aus der Datei zum `~/.config/oomox/colors/` ein:

![](https://raw.githubusercontent.com/wiki/themix-project/oomox/images/examples/contribute_3.png)

6. Schläg neue Datei vor (die eine Pull Request erstellen wird):

![](https://raw.githubusercontent.com/wiki/themix-project/oomox/images/examples/contribute_4.png)

7. :fireworks:
