# Features

## Smooth

Smooth transitions. Eye-pleasing animations. Great performance. Highly responsive.

![](/_app/immutable/assets/smooth_default.BtJ_3R7f.webp) ![](/_app/immutable/assets/smooth_hover.BGPU3dGv.webp)

## Easy to configure

Live reloading config. Easy configuration format. Sensible defaults. Great documentation.

![](/_app/immutable/assets/config_default.CzTps2KE.webp) ![](/_app/immutable/assets/config_hover.n-Kx2XFS.webp)

## Dynamic tiling

Automatic tiling that just works. Supports multiple fine-tuneable layouts, with even more
as plugins.

![](/_app/immutable/assets/tiling_default.BN4gbYOw.webp) ![](/_app/immutable/assets/tiling_hover.C5-2lWTT.webp)

[Tearing support](https://wiki.hypr.land/configuring/extra/tearing/) [Socket-based IPC](https://wiki.hypr.land/ipc/) [Window groups](https://wiki.hypr.land/configuring/core/dispatchers/#grouped-tabbed-windows) [Special workspaces](https://wiki.hypr.land/configuring/core/dispatchers/#special-workspaces)

Hypractive development

[Global shortcuts for apps](https://wiki.hypr.land/configuring/core/binds/globals/) [Touchpad gestures](https://wiki.hypr.land/configuring/core/binds/gestures/)

## Unlock full power

Get the latest features Linux offers. Have full control over your workflow by customizing
and extending it how you want.

Plugins. Customize everything with official and community extensions. Write your own easily with C++

Bindings and IPC. Control your desktop with your favourite languages or simply via IPC.

[Check out more plugins](/plugins/)

[Also see Awesome Hyprland](https://github.com/hyprland-community/awesome-hyprland)

A list of plugins, bindings, apps and more made by the community

# Install now

For your favourite distro

![Arch Logo](data:image/svg+xml...)Arch

>

pacman -S hyprland

Copied to clipboard ✔

AUR git version: [hyprland-git](https://aur.archlinux.org/packages/hyprland-git/)

![NixOS Logo](data:image/svg+xml...)NixOS

>

programs.hyprland.enable

Copied to clipboard ✔

[See more details and git version ↗](https://wiki.hypr.land/nix/)

![FreeBSD Logo](data:image/svg+xml...)FreeBSD

>

pkg install hyprland

Copied to clipboard ✔

![openSUSE Logo](/_app/immutable/assets/opensuse.DK6UxcrZ.svg)openSUSE ![](data:image/webp;base64...)

>

zypper in hyprland
