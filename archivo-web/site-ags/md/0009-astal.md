# AstalCreate Beautiful Widgets With Ease

The Linux Suite to Craft Desktop Shells and Widgets with GTK!

[Introduction](/astal/guide/introduction)

[References](/astal/guide/libraries/references)

![](/astal/icon.svg)

## Use Your Preferred Language

Astal is written with GLib and it supports languages that support GObject introspection.

## No bash scripts needed

Includes modules to work with Network, Bluetooth, Battery, Audio and [more](/astal/guide/libraries/references#astal-libraries).

## Use any Gtk widget

With Astal you work with Gtk directly. You are not limited to only a set of them.
